# System Design

Direktori ini berisi pembahasan desain sistem, baik *High-Level Design* (HLD) maupun *Low-Level Design* (LLD):

- **High-Level Design (HLD)**: Skalabilitas, *load balancing*, *caching*, *database sharding/replication*, *message queue*, dan studi kasus sistem terdistribusi.
- **Low-Level Design (LLD) & Design Patterns**: OOP, prinsip SOLID, *creational/structural/behavioral patterns*, serta desain kelas dan API.
