# Cheatsheets

Direktori ini berisi ringkasan cepat dan referensi inti untuk persiapan *review* singkat:

- Kompleksitas waktu & ruang (Big-O) berbagai algoritma dan struktur data.
- Pola penyelesaian masalah (*Two Pointers*, *Sliding Window*, *BFS/DFS*, *Binary Search*, dsb.).
- **CS Fundamentals**: Database (SQL/NoSQL, *indexing*, ACID), Operating Systems (*concurrency*, *memory*), dan Computer Networking.
- Sintaks dan idiom penting bahasa pemrograman yang digunakan.
