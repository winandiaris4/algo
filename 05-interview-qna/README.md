# Interview QnA & Simulasi

Direktori ini berisi kumpulan pertanyaan *interview* dan catatan simulasi (*mock interview*):

- **Technical QnA**: Pertanyaan konseptual (DSA, System Design, CS Fundamentals, serta bahasa/framework terkait).
- **Behavioral Interview**: Daftar pertanyaan umum dan kerangka jawaban menggunakan metode **STAR** (*Situation, Task, Action, Result*).
- **Mock Interview Notes**: Catatan evaluasi, *feedback*, dan area perbaikan dari setiap sesi simulasi.
