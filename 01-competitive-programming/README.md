# Competitive Programming

Direktori ini berisi catatan materi, implementasi kode, dan pembahasan soal terkait:

- **Data Structures**: Array, Linked List, Stack, Queue, Tree, Graph, Heap, Trie, Union-Find, dsb.
- **Algorithms**: Sorting, Searching, Recursion, Backtracking, Dynamic Programming, Greedy, Graph Traversal, dsb.
- **Mathematics & Logic**: Number theory, combinatorics, modular arithmetic, bit manipulation, dan logika pemecahan masalah.
